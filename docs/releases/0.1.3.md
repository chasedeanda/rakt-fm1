## RAKT 0.1.3

- **Studio EDIT** shuffles the progression, parts, key, scale, meter and tempo within the selected genre. During playback, the new take starts at the next bar. Custom drafts keep their harmony and meter. External MIDI clock continues to set the tempo when selected.
- **Sound EDIT** shuffles tones, drum kits and FX presets. Each musician draws from a genre-specific set of effects, with longer delays and reverbs placed around the other parts.
- **Zoomed-in EDIT** changes only the selected musician, so you can try a new phrase or sound while the rest of the band keeps playing the same song.
