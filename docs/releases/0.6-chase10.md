# Chase FM-1 0.6-chase10

A new warm boot sound for the [CORD startup screen introduced in 0.6-chase9](0.6-chase9.md).

- **Short Dm7 signature.** Four soft electric-key notes—D, F, A and C—roll upward
  and fade out over 1.1 seconds. The tone matches the chord in the piano-key logo.
- **Existing sound control.** Use **GLO → Display → K3 BOOT SND**. Turning it On
  previews the sound; Off cancels a queued sound or fades one already ringing.
  The setting is saved independently of Motion. MASTER controls its output level.
- **Playing takes priority.** A first note cancels a queued chime. If it is already
  ringing, a note or overload request fades it within 256 samples (about 5.8 ms).
  Startup sound remains disabled in SAFE mode.

The chime uses its own small voice after the effects and before MASTER. It does
not select a preset, change the progression, emit MIDI notes or add recorded note
events. It appears in the complete USB stereo mix; the chord/bass stems stay clean.

[Listen to the selected firmware render](../audio/rakt-boot-chime.wav).
[Implementation and verification](../RAKT-BOOT-SOUND.md).

Download **`coralflower-0.6-chase10.fwsc`**, back up current data, then choose that
file in the [custom-build installer](https://ficusficusov.github.io/CoralFlower/#own).
The `.bin` is an inspectable application image, not the installer package. INFO
reports **CoralFlower 0.6-chase10**; package identity remains **FM-1_930**.

Host checks cover the selected audio checksum, exact duration, level/headroom,
sample-independent note timing, mute, saved preferences, SAFE mode, cancellation
and first-key physical/USB/MIDI comparisons at both sample rates. Device listening
and startup/input timing still need physical verification.
